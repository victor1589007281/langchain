# LangChain 运行原理与流程

## 1. 概述

本文档深入解析 LangChain 的执行机制，包括链式调用、流式处理、批量处理等核心流程。

### 2.2 执行流程代码解析

```python
# RunnableSequence.invoke 的核心逻辑
def invoke(self, input: Input, config: RunnableConfig | None = None) -> Output:
    # 1. 设置回调和上下文
    config = ensure_config(config)
    callback_manager = get_callback_manager_for_config(config)

    # 2. 启动根运行
    run_manager = callback_manager.on_chain_start(
        None,
        input,
        name=self.get_name(),
    )

    input_ = input

    # 3. 依次调用每个步骤
    try:
        for i, step in enumerate(self.steps):
            # 为每个步骤创建子运行
            config = patch_config(
                config,
                callbacks=run_manager.get_child(f"seq:step:{i + 1}")
            )
            # 执行步骤
            input_ = step.invoke(input_, config)

    # 4. 完成运行
    except BaseException as e:
        run_manager.on_chain_error(e)
        raise
    else:
        run_manager.on_chain_end(input_)
        return input_
```

## 3. 流式处理原理

### 3.1 流式处理时序图

```mermaid
sequenceDiagram
    participant **User** as **用户代码**
    participant **Chain** as **Chain**
    participant **Model** as **ChatModel**
    participant **Parser** as **OutputParser**

    User->>Chain: **stream(input)**
    activate Chain

    Chain->>Model: **stream(messages)**
    activate Model

    loop **持续生成**
        Model-->>Chain: **chunk1**
        Chain->>Parser: **parse(chunk1)**
        Parser-->>Chain: **parsed_chunk1**
        Chain-->>User: **yield parsed_chunk1**

        Model-->>Chain: **chunk2**
        Chain->>Parser: **parse(chunk2)**
        Parser-->>Chain: **parsed_chunk2**
        Chain-->>User: **yield parsed_chunk2**
    end

    Model-->>Chain: **final_chunk**
    deactivate Model
    Chain->>Parser: **parse(final_chunk)**
    Parser-->>Chain: **parsed_final**
    Chain-->>User: **yield parsed_final**
    deactivate Chain
```

### 3.2 流式处理的实现

```python
def stream(self, input: Input, config: RunnableConfig = None) -> Iterator[Output]:
    """流式输出实现"""

    # 设置回调
    config = ensure_config(config)
    callback_manager = get_callback_manager_for_config(config)

    # 启动流式处理
    run_manager = callback_manager.on_chain_start(
        None, input, name=self.get_name()
    )

    try:
        # 逐步处理每个组件
        for i, step in enumerate(self.steps[:-1]):
            # 非流式步骤：完整执行
            input = step.invoke(input, config)

        # 最后一个步骤：流式输出
        final_step = self.steps[-1]
        for chunk in final_step.stream(input, config):
            yield chunk

    except BaseException as e:
        run_manager.on_chain_error(e)
        raise
    else:
        run_manager.on_chain_end(None)
```

### 4.2 批量处理的实现

```python
def batch(
    self,
    inputs: List[Input],
    config: RunnableConfig | List[RunnableConfig] = None,
    *,
    max_concurrency: Optional[int] = None,
) -> List[Output]:
    """批量处理多个输入"""

    # 获取配置列表
    configs = get_config_list(config, len(inputs))

    # 获取执行器（线程池）
    with get_executor_for_config(configs[0]) as executor:
        # 提交所有任务
        futures = [
            executor.submit(self.invoke, input, config)
            for input, config in zip(inputs, configs)
        ]

        # 等待所有任务完成
        results = [future.result() for future in futures]

    return results
```

## 6. Agent 执行循环

### 6.1 Agent 工作流程

```mermaid
sequenceDiagram
    participant **User** as **用户**
    participant **Agent** as **Agent**
    participant **LLM** as **语言模型**
    participant **Tools** as **工具集**

    User->>Agent: **提出问题**

    loop **Agent循环**
        Agent->>LLM: **发送问题 + 历史 + 可用工具**
        activate LLM
        LLM-->>Agent: **决策（工具调用 或 最终答案）**
        deactivate LLM

        alt **需要调用工具**
            Agent->>Tools: **执行工具调用**
            activate Tools
            Tools-->>Agent: **工具返回结果**
            deactivate Tools
            Note over Agent: **将结果添加到历史**
        else **返回最终答案**
            Agent-->>User: **返回答案**
            Note over Agent: **结束循环**
        end
    end
```

### 6.2 Agent 执行详细流程

```mermaid
stateDiagram-v2
    [*] --> **接收问题**

    **接收问题** --> **构造Prompt**

    **构造Prompt** --> **LLM推理**

    **LLM推理** --> **解析输出**

    **解析输出** --> **判断类型**

    **判断类型** --> **执行工具**: AgentAction
    **判断类型** --> **返回结果**: AgentFinish

    **执行工具** --> **记录观察**
    **记录观察** --> **构造Prompt**: 继续循环

    **返回结果** --> [*]

    note right of **LLM推理**
        模型决定下一步行动：
        - 调用哪个工具？
        - 传递什么参数？
        - 或者给出最终答案？
    end note

    note right of **执行工具**
        工具执行可能包括：
        - 搜索数据库
        - 调用API
        - 计算结果
    end note
```

### 6.3 Agent 循环示例

```python
# 简化的 Agent 执行逻辑
def run_agent(question: str, tools: List[Tool], max_iterations: int = 10):
    """Agent 执行循环"""

    history = []

    for i in range(max_iterations):
        # 1. 构造提示（包含问题、历史、可用工具）
        prompt = build_prompt(question, history, tools)

        # 2. LLM 推理
        response = llm.invoke(prompt)

        # 3. 解析输出
        action = parse_agent_output(response)

        # 4. 判断类型
        if isinstance(action, AgentFinish):
            # 返回最终答案
            return action.return_values

        elif isinstance(action, AgentAction):
            # 执行工具
            tool = get_tool(action.tool)
            observation = tool.invoke(action.tool_input)

            # 记录到历史
            history.append({
                "action": action,
                "observation": observation
            })

    raise ValueError("超过最大迭代次数")
```

|------|----------|----------|
| **多个独立任务** | 使用 `RunnableParallel` | 减少总时间 |

## 11. 总结

### 核心执行模式

| 模式 | 适用场景 | 特点 |
|------|----------|------|
| **invoke** | 单次调用 | 简单直接 |
| **batch** | 批量处理 | 并行优化 |
| **stream** | 实时交互 | 降低延迟 |
| **ainvoke** | 异步IO | 高并发 |

### 关键设计

1. **统一接口**：所有组件实现 Runnable
2. **组合优先**：使用 `|` 操作符组合
3. **回调系统**：完整的生命周期监控
4. **错误处理**：重试、降级机制
5. **性能优化**：并行、缓存、流式
